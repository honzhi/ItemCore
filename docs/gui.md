# GUI 系统

## 打开方式

```
/ic open
/ic gui
```

需要 `itemcore.command.gui` 权限（默认 OP）。

## 主菜单

主菜单按 `categories.yml` 中每个分类的 `slot` 摆放分类图标，点击进入该分类的物品列表。

```
┌────────────────────────────┐
│ 📚 所有物品                │
│ ┌───┬───┬───┬───┬───┬───┐ │
│ │武器│护甲│工具│饰品│食物│   │ │
│ └───┴───┴───┴───┴───┴───┘ │
└────────────────────────────┘
```

## 物品列表

物品列表默认按照从左到右、从上到下的顺序排列。`armor` 护甲分类使用专属的纵向排列规则：物品从上到下填充当前列，再继续填充下一列；点击物品时仍会对应到正确的物品。

```
┌────────────────────────────┐
│ ←返回               ✕关闭 │
│ ┌───┬───┬───┬───┬───┬───┐ │
│ │物A│物B│物C│物D│物E│物F│ │
│ └───┴───┴───┴───┴───┴───┘ │
│ ←上一页          下一页→    │
└────────────────────────────┘
```

预览中随机属性显示为 `min-max` 范围、随机品质逐行显示各品质概率，不会预先抽取。

## 操作

- 左键：获取物品（需要 `itemcore.gui.obtain` 权限与物品自身的 `permission`）
- Shift+左键：查看物品详情

## RPG 信息 GUI

```
/icrpg info [玩家]
```
